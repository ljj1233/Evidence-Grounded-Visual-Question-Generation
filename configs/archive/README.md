# Representative historical configurations

These are selected historical configurations, not a complete reproduction kit for abandoned experiments. See the [historical experiment index](../../docs/archive/HISTORICAL_EXPERIMENT_INDEX.md) for canonical conclusions and original assets.

Retained: P1strong, UVFC+violation RFT, replay RFT, static online UVFC, LatentCov, Explore-Ground distillation. Extra seed variants are covered by retained multiseed result summaries. The G1 `static_relativeguard.yaml` matched ablation and generic `ablation_contract.yaml` are conservatively retained for comparison/audit value.

The two configurations in `configs/phase3a/` remain because the preserved tests load them. Current final configurations are in `configs/new_vqg/`, `configs/phase5c/`, `configs/baselines/` and `configs/gqa_native/`.
