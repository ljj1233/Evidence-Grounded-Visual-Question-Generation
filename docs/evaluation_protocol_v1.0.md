# Evaluation protocol v1.0

冻结日期：2026-11-11。适用：ScienceQA原始hint+image，阶段二plain/strong及后续同批锚定比较。主协议身份为three-phase-prompt-v1；本文件的SHA256、模型配置、Prompt快照和材料清单共同构成运行契约。冻结后不原位修改；发现问题只保留证据、记录局限，不为本批结果改定义。

## 1. 审核来源与证据地位

用户明确委托Codex执行原称“人工审核”的工作。实际来源记录为user_delegated_ai，审核者为Codex；不写成人类标注，不自动填充human标签。最终裁定使用adjudicated字段，初始模型标签保留automatic字段。该审核可用于本次用户授权的流程冻结，但不是独立人类金标准或人类一致性验证。

本轮逐图复核只取原始T、I和固定Q，先封存问题标签，再查看四条件回答及自动结果。会话此前出现过自动诊断，故不声称完全盲、完全独立；记录这一既有暴露。生成方法名、生成端证据、BDR和自动标签不作为判定依据。

## 2. 五维判据

每维采用1/0/null，分别为通过、不通过、未决；已完成审核的null是最终未决，不等于尚未审核。无效Q的必要性、整合性可记not_applicable，必须说明原问题为何无可支持答案。

| 维度 | 通过 | 不通过或边界 |
|---|---|---|
| 有效性V | 题意、指代、预设成立；材料支持可核验答案范围 | 错误预设、歧义或材料不支持为0；不可辨读/有争议为null |
| 相关性R | 主题、对象、所指内容与原T/I相符 | 仅内容匹配；不要求两个模态都参与。预设错误不自动等于不相关 |
| 文本必要性D_T | 缺T后丢失不可由Q、I或允许常识恢复的特定信息 | 给出完整无T解法可判0；“根据文本”字样不构成必要性 |
| 图像必要性D_I | 缺I后丢失不可由Q、T或允许常识恢复的特定视觉事实 | 关键读数被T/Q复述则0；指向“图中”不自动构成必要性 |
| 整合性S | T规则/约束与I事实共同完成同一目标 | 两个互不影响子问题拼接为0；不能用推理步数或题干长度替代判断 |

必要性为1须说明移除后缺什么、为何不可恢复，并定位文本片段/图中位置。为0须给可检查的替代路径。答题模型答对、答错或拒答都不能单独证明信息必要性。

## 3. 常识与材料边界

允许通常中学学科概念、简单算术、遗传显隐性的一般机制、食物链角色、基本物理模型。物种特定的等位基因—表型映射、实验时长、个体偏好、图形编码单位不因主题常见而自动当作已知。

“普通高中生无需材料可作答”需要说明具体的一般知识如何补齐任务事实；不能把某个读者可能记得的冷门地点或物种习性泛称常识。仅因Q已经给齐事实而能作答，优先记题干泄露；若还需常识补齐独立缺失事实，可同时记常识替代。

示意图外形相同不自动证明真实体积相同，未经标度不能据图推实际容积。课堂气体模型可在明确限定平衡理想气体时比较压力；平均速率不能直接当作均方根速率。该标准模型下两者有固定关系，比较要结合N/V和粒子质量；不能只凭速度猜压力。模型边界核验来源：[OpenStax压力与均方根速率](https://openstax.org/books/university-physics-volume-2/pages/2-2-pressure-temperature-and-rms-speed)、[分子速率分布](https://openstax.org/books/university-physics-volume-2/pages/2-4-distribution-of-molecular-speeds)。这不允许给原材料添加新的特定实验条件。

粒子示意图中的“一球代表一粒子”按文本编码处理。溶剂体积不等于溶液体积；可问每mL溶剂对应的模型溶质粒子数，不据此冒称真实摩尔浓度。磁铁“同材质”不保证同磁化强度，无法核验的力大小比较保持待审，不补造场强标定。

## 4. 五类捷径

多标签独立记录：text_only表示Q+T足够；image_only表示Q+I足够；两者不要求另一条件答错，因此自足Q可同时通过。common_knowledge须有普通学科知识替代特定材料事实的可核验路径。question_leakage指Q提供或等价包含关键求解事实。independent_stitching指可拆成互不制约、分别依赖模态的子问题。

交叉表用互斥展示桶，避免重复计数：有效且相关的题依次归入拼接、常识/题干捷径、单模态足够、双必要且整合、未决。五类捷径正式分布仍保留多标签，不因展示桶改变标签。所有比例仍除以全部预安排名额N。

## 5. 参考答案、作答与评分

答案与当前Q哈希绑定；不沿用ScienceQA原题答案。独立答案建立和核验使用新会话；同一模型一致仅为verified_automatic，不能伪装独立金标准。委托复核独立建立/核对答案，来源记user_delegated_ai。

TI/T/I/0使用完全相同Q与答题规则，仅改变可见材料；移除模态时移除其OCR、caption、摘要、生成证据，条件间无对话历史。标准答案与审核结论不进入答题器。允许普通学科知识，不允许猜补缺失的特定事实。

正确须覆盖Q要求的全部要点，无实质错误；接受等价改写/单位。Q只问结果不能强加理由；明确要求解释时须满足必要解释。错误结果、关键遗漏或实质矛盾解释记0。拒答、参考答案未核验、解析/技术失败或争议记null，不将拒答当错。原题错误预设即使答题器正确反驳，也不把原Q改判有效。

## 6. 固定分母与三值指标

每材料每方法预安排一个问题名额。四种方法各30个，共120个；阶段二只启用plain与strong，报告各N=30及合计N=60；另60名额保持pending。技术重试不新增名额；生成语义失败不重采样。

有效率=确认有效数/N。四条件正确率=确认V=1且该条件正确数/N。BDR逐题为V AND C_TI AND NOT C_T AND NOT C_I；已知零项可短路确定0，其余未知传播；不额外要求C_0=0。五维通过率=各维通过数/N；捷径占比=有效且该捷径确认存在数/N。多标签并集去重。

无Q的确定失败为无有效产出，留在N；已有Q但待核验不直接判无效。每项报告通过、不通过、不适用、未决，和[通过/N,(通过+未决)/N]边界；边界不是抽样置信区间。N=0时比例为null。

## 7. 本轮边界案例

- c02：四格基因型只读I即可，V/R通过，D_T失败；“图中”确实定位I，但不使T必要。
- c06：粉红等位基因隐性只读T即可，V/R通过，D_I失败。
- c03/c07：Q复述全部决定性事实，属题干泄露；相关性仍可通过。
- c01/c05：物种特定表型规则与方格基因型共同求比例；单模态拒答使行为BDR未决，不推翻信息必要性。
- c11：国家与中间生物分别需要T/I，却是独立子问题，S失败；BDR不能自动排除拼接。
- c04/c08/c12：错误预设使V失败，但R仍可通过；不把反驳原题当作原预设成立。

## 8. 材料准入与运行冻结

逐项完成12条准入：原始非空hint、原图可读、来源可追溯、文本实质作用、图像独有作用、共同目标、无额外特定事实、无原答案泄露、筛选见证隔离、开发来源隔离、重复来源检查、先筛后生成。全部通过才纳入；待审不当通过。先完整审核原60组，不足时沿同一冻结随机框/种子顺序追加，不替换旧候选、不降低标准。按累计顺序取前30个通过者。相同图像不重复纳入，模板族组成另外披露，不声称跨模板独立泛化。

正式运行须校验本协议SHA256、冻结材料哈希、Prompt快照与实际模型身份。plain30全部终态后再strong30。失败保留；显式重评只创建关联的新评测运行，保留原Q和原始输出，不替换坏题。先生成自动趋势报告，再按预固定seed、每方法8题抽取26.7%复核，不按结果好坏挑样；自动异常先查输入/日志，不借异常重新出题。

重复性校验采用3个固定dev问题各5次相同实际输入的新HTTP请求。仅5次原始字符串完全一致且请求载荷一致，才称本次样本上的“等效贪心重复性通过”；不声称已证明后台解码机制或未来必然确定。实际不可配置参数记null，不虚构生效值。
