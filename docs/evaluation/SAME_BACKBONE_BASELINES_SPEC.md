# Same-backbone baseline faithfulness specification

This document freezes the method interpretation **before any full baseline
training**. The baselines use `/hpc2hdd/home/fye374/models/Qwen3-VL-8B-Instruct`
and the project image/question split. They are documented same-backbone
reimplementations/adaptations, not exact reproductions of the published
systems.

## Sources inspected

* ConVQG, Mi et al., AAAI 2024, paper and supplementary equations:
  <https://arxiv.org/abs/2402.12846> and
  <https://ojs.aaai.org/index.php/AAAI/article/view/28216>.
* Guiding Visual Question Generation, Vedd et al., NAACL 2022, paper and
  official repository at commit `ffe7011750c23bdea44001e5ba4f750f1411f0f0`:
  <https://aclanthology.org/2022.naacl-main.118.pdf> and
  <https://github.com/nihirv/guiding-vqg>.
* Information Maximizing VQG answer-category resource used by Guiding VQG:
  <https://cs.stanford.edu/people/ranjaykrishna/iq/iq_dataset.json>.
* Self-Evolving Visual Questioner (SeeQ), paper and official repository at
  commit `18e795293808c5cf9f69f1e980577ab40b3faa95`:
  <https://arxiv.org/abs/2606.13929> and
  <https://github.com/tianyi-lab/SeeQ>.

The original ConVQG implementation is BLIP ViT-B/BERT and its text constraint
may be an answer, caption, or knowledge triplet. The original Guiding VQG code
uses BERT, ResNet/bottom-up detector features, and answer-category annotations
from the Information Maximizing VQG release. SeeQ's released generation code
contains proposer, answerer, rewrite, self-judge/filter, image-fact cache, and
sample-bank/RAG paths; it does not ship trained checkpoints or data.

development1000, reward-calibration, and final-holdout IDs. Every generated
cache is keyed by canonical image ID plus model/prompt/config hashes and is
written in stable record-ID order.

## B2 — ConVQG-inspired Auto-Caption Contrastive Grounding

### ORIGINAL METHOD

ConVQG feeds an image and a textual constraint to a multimodal encoder-decoder.
Frozen image-only (IQGM) and text-only (TQGM) generators produce negative
questions. A trainable joint question representation is pulled toward the
ground-truth question and pushed away from each unimodal negative with two
triplet terms. The paper combines them as
`CL = alpha*CL_txt + (1-alpha)*CL_img`, with `alpha=0.2`, margin `0.5`, and
`Loss=(beta*CL+CE)/2`; IQGM/TQGM are dropped at inference.

### PRESERVED

* dual image/text negative generators and frozen negative representations;
* masked-mean question representation over target question tokens;
* both triplet terms, alpha 0.2, margin 0.5, CE plus weighted CL objective;
* joint multimodal conditioning during training and auxiliary-module removal
  during inference.

### ADAPTED

* Qwen3-VL image/text branch and LoRA replace BLIP ViT/BERT;
* the text constraint is a single deterministic factual caption generated by
  the frozen Qwen3-VL base model, `t=Cap(I)`;
* Qwen3-Embedding-4B supplies the fixed normalized `z_gt`, `z_img`, and
  `z_txt` spaces; a trainable Qwen-hidden-to-embedding projection supplies
  `z_joint`;
* project optimizer, two epochs, effective batch 16, max length 512 replace
  BLIP's dataset-specific schedule.

### DROPPED

* oracle VQA answer, human caption, knowledge triplet and any GPT teacher;
* BLIP-specific beam-search and architecture; answer-conditioned inference.

### ADDED FOR MODERN BACKBONE

* deterministic caption cache keyed by image/base/prompt hashes;
* token-level teacher-forced hidden-state pooling and projection;
* explicit beta schedule and pre-full-run CE/CL/gradient scale report.

### TRAIN-TIME EXTRA SUPERVISION

The 50k human questions are the only gold supervision. The caption and both
negative questions are frozen model outputs; Qwen3-Embedding-4B embeddings are
fixed auxiliary signals.

### INFERENCE-TIME EXTRA INPUT

Raw user input is the image. The internal frozen captioner supplies one caption
to the B2 model. No answer, human caption, category, or target question is
provided. Classification: `SAME_BACKBONE_DOCUMENTED_ADAPTATION`,
`DIRECT_RAW_IMAGE_BASELINE` with `WITH_INTERNAL_FROZEN_CAPTIONER`.

### SAMPLE COUNT

One caption, one image-only negative and one text-only negative per unique
training/dev/evaluation image; one generated question per image for greedy and
four for sampled evaluation.

### COMPUTE DIFFERENCE

Training adds one offline pass of the frozen Qwen captioner, two frozen negative
passes, and one offline embedding pass; it adds a small projection and contrastive
forward/backward computation. Inference adds one frozen captioner generation
before each B2 generation.

## B3 — Guiding VQG implicit-guided adaptation

### ORIGINAL METHOD

Guiding VQG's implicit variant predicts a relevant object subset and one of 16
answer categories from image-derived concepts, uses hard Gumbel-Softmax for the
discrete latent selections, and injects selected object/category features into
the decoder. Training uses target question/answer information to construct
posterior and object-alignment supervision; inference uses image-derived
features only. The official 16 categories are exactly:
`count, binary, predicate, material, time, color, attribute, object, stuff,
food, shape, other, location, animal, spatial, activity`.

### PRESERVED

* image-only inference;
* frozen detector/object candidates, hard straight-through Gumbel selection,
  `k=2`, deterministic top-2 at evaluation;
* 16-way category prediction and internal guide representations;
* additive question, category, and object-selection losses.

### ADAPTED

* Qwen3-VL visual tokens replace the original ResNet/BERT encoder-decoder;
* selected detector features and predicted category embeddings are projected
  to a small number of soft guide tokens inserted before question decoding;
* project LoRA, bf16, two-epoch, effective-batch-16 schedule replaces the
  original full-model schedule.

### DROPPED

* gold answer/category/object text at inference;
* original fairseq/BERT decoder and untracked legacy preprocessing;
* any question-type heuristic or invented taxonomy.

### ADDED FOR MODERN BACKBONE

* explicit cached detector feature schema and deterministic top-2 fallback;
* guide-token projection compatible with Qwen3-VL processor inputs;
* category/object target records and a hard-gating diagnostic that verifies
  guides change logits.

### TRAIN-TIME EXTRA SUPERVISION

For each of the exact 50k SFT records, the VQAv2 train annotation answer is
used only to map to the official 16-way category. Detector concepts are ranked
against target question/answer text using the released concept-alignment
construction; this produces a multi-label object-selection target. These fields
never enter inference. If the released category annotation or detector feature
inputs cannot be recovered, B3 data construction must stop rather than silently
substitute a question-type heuristic.

### INFERENCE-TIME EXTRA INPUT

Image only. The pipeline is frozen detector → candidate concepts → learned
selector → predicted category → internal guide tokens → Qwen3-VL.

### SAMPLE COUNT

Exactly 50,000 human-question records for two epochs; one greedy and four sampled
questions per development image at evaluation.

### COMPUTE DIFFERENCE

Training adds one detector-feature pass/cache, selector/category heads, and three
loss terms. Inference adds detector features and a small selector/category
forward pass; no textual answer/category is supplied.

## B4 — SeeQ-style post-SFT self-evolution

### ORIGINAL METHOD

SeeQ repeatedly uses the current VLM as proposer/answerer, rewrites proposals
with a frozen stable reference, filters for answerability/grounding/ambiguity and
improvement, retains accepted QA triples, then trains in both questioner (QG)
and answerer (QA) formats. The released workflow also includes deterministic
image facts and a sample-bank/RAG path.

### PRESERVED

* `M_t` proposal → answer → fixed-`M0` rewrite → fixed-`M0` filter;
* unlabeled-image-only construction from the 50k train image universe;
* rejection reasons, sample-bank/fact artifacts, deterministic candidate order;
* exactly 10,000 retained `(image, question, answer)` triples per round;
* both QG and QA records (20,000 formatted records per round);
* two-round capability with `M0→M1` and `M1→M2`, retaining/evaluating R1 and R2.

### ADAPTED

* `M0` is the existing final SFT LoRA checkpoint and remains frozen for all
  rewrite/filter calls;
* Qwen3-VL-8B with project LoRA replaces the released model/checkpoint choices;
* project image paths, prompts and one-epoch-per-round training use the released
  SeeQ generation logic where applicable.

### DROPPED

* all human VQA questions, answers, annotations and GPT/OpenAI teachers during
  evolution; Luna/GPT-4o remain evaluators only;
* any unavailable proprietary checkpoint or unreleased data.

### ADDED FOR MODERN BACKBONE

* stable `M0` hash and adapter-copy lineage checks;
* resumable cache files for proposals, answers, rewrites, filters, facts and
  sample-bank state;
* explicit exact-count assertion and dual-format count assertion.

### TRAIN-TIME EXTRA SUPERVISION

Only retained synthetic QA triples produced by the self-evolution loop. Human
questions and answers are not read during proposal, rewrite, filtering, or
training-data construction.

### INFERENCE-TIME EXTRA INPUT

Image only for baseline generation. Internal proposer/filtering is used only to
construct training data, not at evaluation generation time.

### SAMPLE COUNT

Exactly 10,000 retained triples and 20,000 QG/QA records in each of R1 and R2.
If the acceptance rate is too low, the deterministic schedule consumes more of
the permitted 50k images; it never silently lowers the target count.

### COMPUTE DIFFERENCE

Each round adds multiple batched Qwen passes for proposal, answer, rewrite and
filtering, plus one one-epoch LoRA adaptation. R2 proposes with M1 but keeps the
same frozen M0 rewrite/filter reference.

## Classification and stop conditions

B2 is `SAME_BACKBONE_DOCUMENTED_ADAPTATION`; B3 is
`SAME_BACKBONE_REIMPLEMENTATION` only when the official category and detector
inputs are recovered, otherwise `SAME_BACKBONE_DOCUMENTED_ADAPTATION`; B4 is
`SEEQ_STYLE_POST_SFT_ADAPTATION`. None may be called an exact reproduction.

Before full training, data, forward/backward, tiny-overfit, and 16-image
generation smokes must pass for each baseline. This phase must stop and report a
blocker if the B3 official category/detector inputs cannot be reconstructed or
if any exact-count/data-boundary assertion fails. GRPO, VIC/violation-reward
training, preference data, and final-holdout evaluation are outside this phase.
