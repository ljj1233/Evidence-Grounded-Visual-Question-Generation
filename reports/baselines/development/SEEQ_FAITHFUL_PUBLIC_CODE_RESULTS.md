## 2. Core mechanism vs. what was fixed

The earlier `seeq_style` run collapsed at the proposal stage. This run replaces the
three core mechanisms:

1. **Multi-intent proposal (CORE FIX #1).** Five paper intents
   (`direct_recognition, comparison, spatial_relations, scene_understanding,
   grounded_reasoning`), 2 samples each → `K=10` proposals/image, using the paper's
   Fig. 2 proposal prompt (verbatim = `genqa_prompt_v1`) conditioned on the intent.
   The per-intent condition lines are `LOCAL_CONTROLLED_ADAPTATION` because the
   paper names the intents but ships no templates.
2. **Frozen-M0 rewrite (CORE FIX #2).** Rewriter and rewritten-answer generator are
   the **frozen initial checkpoint M0 in both rounds** (paper Eq. 5 / §3.2); the
   proposal answer is generated by `M_t`.
3. **Visual-validity + difficulty-improvement filter (CORE FIX #3).** Acceptance =
   `valid_visual AND (perception_improved OR reasoning_improved)`, using the released
   `hard_constraints` validity gate, `perception = 2*hard + easy`, reasoning step
   count, and `has_difficulty_improved` thresholds, plus the released
   overlap<0.82 / non-duplicate / single-question gates. Parser failure is never
   accepted.

**Not** added: any speculative lexical/compound/dedup/model-following filter beyond
those the released `generation_pipeline.py` actually executes.
**Not** method-core: RAG fact cache / sample bank (`not_method_core = true`); the
released standard, non-RAG evolution instructions are used.

**Main diagnostic — did correcting proposal + rewrite + difficulty filtering
remove the prior collapse? Yes.**
* The old baseline lost semantic diversity (0.524→0.166→0.097) and collapsed
  duplicates (0.347→0.811→0.857) while barely moving visual-centric scores and
  *dropping* Spatial. The faithful run **preserves diversity** (SemDiv ≈ 0.52 flat;
  sampled dup ≈ 0.23) and **substantially improves all four visual-centric
  dimensions**, most notably Spatial (0.081→0.159→0.179).
* Support is preserved at M1 (0.7327→0.7357) and drops at M2 (0.6643); unsupported
  stays low throughout.
* Reference BLEU/CIDEr fall, but the project construct is visual-centric quality
  and diversity (not imitation of VQAv2 reference wording), so this is expected.

## 12. Limitations

* Backbone (Qwen3-VL-8B), M0 (VQAv2 SFT), train image source (COCO train2014),
  LoRA (paper uses full SFT), and judge (GPT-5.6 Luna / GPT-4o) differ from the paper.
* Per-intent proposal lines and the intent→rewrite-instruction mapping are
  `LOCAL_CONTROLLED_ADAPTATION` (paper names intents, ships no templates).
* QG is `image → question` (task contract) rather than the paper's `x → (q,a)`;
  QA is `(x,q) → a`.
* RAG fact cache / sample bank are not used (`not_method_core = true`).
* R2 accepted 6,961 < 10,000; not padded.
* Retention is a project rule (official retention code is unreleased).
* Single seed (42); no development-score tuning; no checkpoint selection.
* Proposal/rewrite SemDiv uses a 1,000-image subset; the SeeQ-aligned sampled-5Q
  diagnostic was not run (greedy + sampled-4 reported).
